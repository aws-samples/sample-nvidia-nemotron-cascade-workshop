# Archived Methodology Lesson

An early 30-ticket synthetic run used internally inconsistent subject/body
pairings, a different evaluation contract, and a post-hoc routing variant.
Its numeric results are intentionally not reproduced here because they are not
publication evidence and are not comparable with the current locked test.

The canonical claim-bearing result is
[`production-shaped-results.md`](production-shaped-results.md). It uses a
coherent production-shaped dataset, scenario-family-separated calibration and
test splits, the predeclared three-rule routing policy, independently reviewed
locked-test labels, provenance-v3 caches, actual input/output token usage, and
a dated pricing snapshot.

The lesson from the discarded run is methodological: synthetic data must be
checked for coherence, policy choices must be fixed before the final test, and
stress demonstrations must not be presented as estimates of production
traffic or economics.
